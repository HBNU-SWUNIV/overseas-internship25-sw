## 인턴쉽 개요
  - ### 기간 : 2025.08.10 ~ 2025.08.23
  - ### 국가 : 말레이시아
  - ### 도시 : 쿠알라룸푸르
  - ### 업체 : UCSI University

## Project Background
  - ### 개요 :
이번 인턴쉽은 말레이시아 쿠알라룸푸르의 UCSI 대학교에서 진행되었으며, 모든 팀이 자산관리 웹 시스템(Asset Management Web)이라는 공통된 주제와 조건을 가지고 프로젝트를 수행하였다.
각 팀은 주어진 조건을 바탕으로 설계, 개발, 배포 과정을 경험하며 웹 서비스 구축 전반에 대한 실습을 진행하였다.
  - ### 필요성:
웹 기반 자산 관리 시스템에 대한 이해 및 구현 경험
데이터베이스 설계와 백엔드·프론트엔드 연동 경험
제한된 기간 내 기획부터 개발까지 수행하는 프로젝트 경험을 통해 실무 능력 강화

## 개발환경
  - ### DBMS : PostgreSQL
  - ### 개발 언어 : Java, JavaScript (Svelte, Node.js)
  - ### 프레임워크 : Spring Boot, SvelteKit
